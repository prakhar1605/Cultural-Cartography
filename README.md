# Cultural Cartography

Cultural Cartography is an audience intelligence and cultural analysis platform that uses NLP techniques to extract insights, themes, and sentiment trends from large-scale social media data.

## 🚀 Features
- Analysis of 50,000+ Reddit posts
- Topic extraction and cultural theme identification
- Sentiment analysis across communities
- Interactive visualization dashboard
- Stakeholder-friendly exploration of engagement metrics

## 🧠 Methodology
1. Data collection from Reddit APIs
2. Text preprocessing and cleaning
3. NLP-based topic and sentiment extraction
4. Aggregation of cultural signals
5. Visualization through interactive dashboards

## 🛠 Tech Stack
- Python
- NLP (TF-IDF / embeddings)
- APIs (Reddit)
- Streamlit

## 📊 Use Cases
- Audience research
- Brand and cultural analysis
- Social trend monitoring
- Qualitative insight generation

## ⚠️ Limitations
- Limited to public Reddit data
- Topic interpretation may require human validation
- Language and regional bias possible
